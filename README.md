# Helix Agents 코드 스타일 가이드

## 1. 코드 작성 원칙

### 1.1 일반 원칙

- 가독성을 최우선으로 고려 (인간이 읽기 쉬운 코드)
- 함수/메서드는 최대 80라인 이내로 제한 (초과 시 리팩토링)

- Inner 함수는 필수적인 경우에만 사용
- Inner 함수 사용 시 반드시 이유를 문서화

### 1.3 타입 힌트

- Python 3.9+ 내장 타입 사용
- 타입 힌트는 명시적으로 작성 (Any 사용 지양)

### 2.1 수정 금지 사항

- **[!중요!]** .venv 내 라이브러리 코드 수정 절대 금지
